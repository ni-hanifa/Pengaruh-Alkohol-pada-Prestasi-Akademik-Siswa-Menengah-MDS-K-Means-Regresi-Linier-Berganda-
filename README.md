# Pengaruh-Alkohol-pada-Prestasi-Akademik-Siswa-Menengah-MDS-K-Means-Regresi-Linier-Berganda-
Proyek analisis data menggunakan R untuk mengevaluasi dampak konsumsi alkohol terhadap nilai akademik siswa sekolah menengah. Pendekatan yang digunakan meliputi Multidimensional Scaling (MDS), K-Means Clustering, dan Regresi Linier Berganda.  Opsi 2 (Bahasa Indonesia - Lebih Singkat)
